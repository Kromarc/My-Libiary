Linux通过命令方式实现对系统的交互，命令格式如下

```
[Command_Name] [option]... [object]...
```

- object 表示`files`或`directory`
- `...`表示支持处理一个或多个`[option] `和 `[object]`
- 操作支持简略写法：
	
	`[commands] -[option_1] -[option_2]...`
	
等价于
	
	[commands] -[option_1][option_2]...

`Linux`命令区分字母大小写
```
example:
	
	ls        #识别 
	
	Ls        #不识别
	
	lS        #不识别
	
	LS        #不识别 
```
# 1 常用命令
## 1.1 `ls`
### [1]介绍

list directory contents.    列出目录内容

**语法**
```
ls [options]... [file]...
	
example：
		
	ls                 -------no [option],no [file] 
		
	ls /usr/bin        -------no [option],with [file]
		
	ls -x	           -------with [option],no [file]
		
	ls -x /usr/bin     -------with [option],with [file]
		
	ls -xlF /usr/bin /home  -------with [option] above two,with [file] above two

You can use commands with more than one [options] and [file],It also works well.
```

### [2]操作

1.无参数

```
ls

# Ignore files and directories starting with a'.' by default
# 默认忽略以'.'作为名称开头的文件或目录输出
```

2.带参数

`--help`

```
ls --help

# Print help information
# 打印帮助信息，这个帮助信息是属于ls命令，无法通过添加目标对象实现对目标对象帮助信息的打印
	
	ls --help 等价 ls --help [command_name]	
	
example:
	ls --help
		
	ls --help sudo 	
	
	两个命令输出内容一致
	
--help 操作可以不借助man命令实现对ls帮助文档的输出
```

`--format`

```
ls --format [type]

# set the display format
# 设置显示格式，即控制系统输出内容的格式

ls --format [Type]
	
	Type类型：
		
		long：显示详细信息
		
		verbose：显示详细信息
		
		single-column：以单列形式输出
		
		columns：以多列形式输出
		
		vertical：以垂直形式输出
		
		horizontal：以水平形式输出
		
		commas：使用逗号分隔的形式输出


ls --format long 和 ls --format verbose 等价于 ls -l
# 这三条命令的作用均为：显示详细信息

ls --format columns 等价于 ls -C
# 这两条命令的作用为：将文件以多列的形式进行显示，
```

`-C`

```

# 将文件以列的形式显示，即优先铺满一列后再换行
```

`--quoting-style`

```
ls --quoting-style=[values]

# Set quoting style
# 设置引用风格
	
	values:
		
		literal              : 字面量
			
			# 直接输出文件项名称本身
		
		locale               : 本地化
			
			# 根据当前系统的 所在地区来决定使用哪种引号
		
		shell                : shell安全风格
			
			# 文件名包含Shell特殊字符：空格、&、*等时，才会加上引号，反之不添加引号
		
		shell-always         :  shell安全风格-强制
			
			# 强制给所有文件名加上引文单引号，不考虑文件名是否包含特殊字符
		
		shell-escape         : shell安全风格-转义
			
			# 以shell安全风格为基础，对文件名中的不可打印字符使用C语言风格的转移序列
		
		shell-escape-always  : shell安全风格-转移-强制
			
			# 强制给所有文件名加上单引号，对不可打印字符进行转义
		
		clocale              : 类C风格
			
			# 使用当前本地化环境下的引号字符
		
		c                    : C语言风格
			
			# 始终使用英文双引号 `""` 包裹文件名，同时使用C语言风格的反斜杠来转义特殊
			  字符
		
		escapes              : 转移风格
			
			# 使用反斜杠转义文件名中的特殊字符和不可打印字符
```

`-c`

```
ls -c

# If the long listing format (e.g., -l, -o) is being used,
  print the status access time instead of the modification time.
 
  When explicitly sorting by time (--sort=time or -t) or when not using a 
  long listing format,
  sort according to the status change time.
# 如果长列表项格式：例如(e.g.=for example): -l, -o. 被使用，则使用最近访问时间来替换文件内
  容修改时间进行在长列表格式中进行打印
  
  当对文件按时间进行排序，或没有使用长监听格式，则通过change time(ctime)进行排序
```
