### 1 `man`手册中英文配置

#### 1.  安装中文`man`手册

安装命令：

```
sudo apt-get install manpages-zh
```

卸载命令：

```
sudo apt-get remove manpages-zh
```


#### 2. 查看中文`man`手册安装路径

```
dpkg -L manpages-zh | les
```

#### 3. 设置中文`man`手册命令

查看语言包

```
ls /usr/share/man
```

修改文件 `~/.bashrc`，添加如下命令

```
alias [cn-man] = 'man -M /usr/share/man/zh_CN' 


#[cn-man] 是用户自定义新命令
```

#### 4. bug

下载中文手册后，`man`命令会自动被更换为中文手册，若令其保持不变则修改`~/.bashrc`文件，添加如下命令：

```
alias man='man -M /usr/share/man/'
```

#### 5. 重启命令终端即可
